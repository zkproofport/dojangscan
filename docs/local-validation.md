# 로컬 검증 기록

검증일: 2026-10-07 (Asia/Seoul)

- `npm test`: 17개 통과. EAS v0/v1/v2 서명, 변경된 문서·잘못된 체인·기대한 발행자, proof scope/root/verifier/public-input 정책, 관리 권한과 등록 발행자 구분, 테스트 스키마 calldata, 발급/역할 부여 ABI, 잔액 조건 설계의 원본 정보 제외, 언어 전환.
- `npm run check` / `npm run build`: 타입 검사 및 정적 Vite 빌드.
- `npm run test:live`: GIWA Sepolia 블록 **38,031,720**에서 실제 공개 조회 확인.
  - EAS 도장 50개, 현재 Dojang 스키마 4개, 현재 등록 발행자 10개.
  - 도장 상세, 스키마, tx, 지갑 기본 인덱스, 이전 기록, 공개 RPC CORS, 고정 verifier 정책 오류 처리.
  - EAS·Dojang 계약 10개 코드 확인.
  - 임시 키의 실제 오프체인 예제 서명과 현재 EAS 도메인 버전/취소 조회 확인.
- 별도 헤드리스 Chrome 프로필에서 로컬 브라우저 검증 통과.
  - 한국어 ↔ 영어, 라이트 ↔ 다크 전환 및 새로고침 후 선택 유지.
  - 5개 작업 역할, 관리자 화면, 스키마 calldata 생성, 로컬 잔액 조건 설계.
  - 오프체인 예제 서명/취소 조회 성공, 금액 1원 변조 후 UID 불일치 거부.
  - 가이드·스키마·발행자·Proof Studio 영문 화면에서 한국어 UI 문구 잔여 없음 (언어 변경 버튼 제외).
  - 390px 모바일 가로 넘침 없음, 런타임 예외 없음.
- 실제 `getRoleAdmin` / `hasRole`로 등록 관리자의 역할 부여 권한 확인. 일반 주소는 두 Book에서 등록·부여 권한 없음 확인.
- 일반 스키마 등록 호출을 `eth_call`로 시뮬레이션하여 성공 확인. 거래는 전송하지 않음.
- 자체 임시 지갑의 사용자 지정 오프체인 서명 생성 후 실제 서명자 복원 확인.

현재 SchemaBook과 DojangAttesterBook의 조회 결과:

| 역할 | 현재 권한 주소 |
|---|---|
| DEFAULT_ADMIN_ROLE | `0xE3Fd5228AC2D2C15856959F9e27a4671c5d45958` |
| UPGRADER_ROLE | `0xd72b48Ed00b67D756408a140435D8ef101f4a377` |

코드에서 이 주소들을 하드코딩하여 관리자 판정에 사용하지 않습니다. 역할 로그에서 후보를 찾고 고정 블록의 `hasRole`로 확인했습니다.

공개 RPC의 HTTP 429와 JSON-RPC 개별 rate-limit 응답을 실제 확인하여, 호출을 3개 이하 묶음으로 나누고 최소 650ms 간격 및 최대 세 번 재시도를 적용했습니다. 다른 탭/서비스와 RPC 한도를 공유할 수 있습니다.

이번 작업에서 실제 모바일 proof 생성, relay 완료, 테스트 도장 트랜잭션 발급·취소, 파생 도장 계약 배포는 수행하지 않았습니다. 기존 등록 계약 draft의 9개 정책 테스트는 이전 구현 때 통과한 상태이며, 이번에 해당 Solidity 소스는 변경하지 않았습니다.

소스 푸시 대상은 `zkproofport/dojangscan`입니다. 외부 사이트 배포와 GitHub Actions 설정은 추가하지 않았습니다. 향후 Pages용 빌드 산출물은 `dist/`의 정적 파일입니다.

연결한 브라우저 지갑의 실제 EIP-712 승인 흐름은 자동화하지 않았습니다. 같은 서명 생성 함수는 ethers 임시 지갑으로 검증했습니다. 번들에는 SDK의 큰 WASM 파일이 있어 Vite 청크 크기 경고가 남습니다. SDK와 작업 화면은 필요할 때 불러오도록 분리했습니다.
